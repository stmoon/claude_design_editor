# Claude Design Editor

정적 HTML 덱을 파워포인트처럼 편집하는 로컬 에디터. 프로젝트에 종속되지 않고,
`section.slide` 구조의 HTML 덱이면 어디서든 쓴다.

```bash
python3 editor.py /path/to/decks           # 하위 폴더까지 뒤져 덱을 모두 찾는다
python3 editor.py /path/to/deck.html       # 특정 파일을 연다
python3 editor.py . --port 8770 --no-open   # 브라우저를 띄우지 않는다
```

시작하면 기본으로 브라우저가 자동으로 열린다. `--no-open` 을 주면 열지 않고
주소만 찍어 주므로, 이미 띄워 둔 창에서 열거나 원격에서 붙을 때 쓴다.

폴더를 주면 그 아래 모든 `.html` 을 찾아 도구막대 목록에 올린다. 폴더별로 묶여
나오므로 덱이 여러 폴더에 흩어져 있어도 한 창에서 오간다.

```
decks/
  Docker/1-1_Docker.html
  CMake/1-2_CMake.html      <- 셋 다 목록에 뜬다
  Network/1-3_Network.html
```

각 덱의 `deck.css`, `imgs/` 는 그 덱 폴더 기준으로 읽는다. 그림을 올리면 지금
열려 있는 덱의 `imgs/` 에 저장되고, `다른 이름으로 저장` 도 그 덱과 같은 폴더에 쓴다.
`_` 로 시작하는 파일과 `node_modules` 같은 폴더는 건너뛰고, 6 단계까지만 내려간다.

브라우저가 `http://127.0.0.1:8770/` 로 열린다. 크롬 기준으로 만들었다.

주소에는 지금 열린 파일과 슬라이드가 `?deck=<경로>&slide=<번호>` 로 따라 붙는다.
이 주소를 북마크하거나 새로고침하면 같은 파일, 같은 슬라이드로 바로 열린다.
예: `http://127.0.0.1:8770/?deck=gazebo/GazeboIntroduction/lecture/2-1_GazeboIntroduction.html&slide=6`
파이썬 표준 라이브러리만 쓴다. 설치할 것 없다.

## 화면

- 왼쪽: 슬라이드 목록. 실제 렌더링을 축소한 썸네일이라 보이는 그대로다.
  선택한 장은 굵은 파란 테두리로 표시된다.
  썸네일을 위아래로 끌면 슬라이드 순서가 바뀌고, 페이지 번호와 진행 막대가
  자동으로 다시 매겨진다. 번호가 없는 표지·목차·정리는 번호 계산에서 빠진다.
  끌지 않고 `Alt+↑` / `Alt+↓` 로도 옮길 수 있다. 썸네일을 고른 뒤 `Del` 을 누르면
  그 슬라이드를 지운다. 마지막 한 장은 남으며, 지운 것은 `Ctrl+Z` 로 되돌린다.
  목록 아래 `+ 새 슬라이드` 는 선택한 장 바로 뒤에 새 장을 넣는다. 새 장은
  바로 위 슬라이드를 그대로 복사하되 글만 비운다. 레이아웃, 섹션 이름, 꼬리말은
  그대로라 덱 전체의 디자인이 유지된다.
- 슬라이드가 없는 파일(장절로 이어지는 한 장짜리 문서)은 썸네일 대신 장절 목차를
  보여준다. `h1` / `h2` / `h3` 를 단계별로 들여 쓰고, 누르면 그 자리로 넘어가며
  읽고 있는 장절이 표시된다. 이때는 `+ 새 슬라이드` 도 숨는다.
  기준은 `cde.config.json` 의 `heading` 으로 바꿀 수 있다.
  문서도 슬라이드와 똑같이 고친다. 제목, 문단, 목록, 표 칸, 정의 목록, 코드 블록이
  모두 편집 대상이고, `Ctrl+Z` 와 자동 저장, 글자 크기 조절도 그대로 듣는다.
  블록을 누르면 그 블록만 크기가 바뀌고, 아무것도 안 누르면 문서 전체가 바뀐다.
- 오른쪽: 선택한 슬라이드. 창 크기에 맞춰 자동 축소된다.
- 가운데 회색 띠를 끌면 좌우 폭이 바뀐다.

덱은 iframe 두 개(스테이지 / 목록)로 렌더링한다. 덱 자신의 CSS 가 그대로 쓰이므로
에디터가 모양을 다시 구현하지 않고, 인쇄 결과도 달라지지 않는다.

## 배치 - 등분

**덱을 열기만 해서는 배치를 건드리지 않는다.** 덱이 `.lead`, `.cols`, `.note` 같은
자체 구조를 쓰면 그대로 보여준다. 도구막대에는 `덱 원래 배치` 로 표시된다.
등분을 고르기 전까지는 목록에 없는 이름을 대신 보여주지 않는다.

배치 버튼을 누르면 본문을 어떻게 나눌지 그림으로 고른다. 본문은 **행**으로 나뉘고
각 행은 다시 **칸**으로 나뉜다. `2-1` 은 위에 두 칸, 아래에 한 칸이라는 뜻이다.

| 고르기 | 나뉨 |
| --- | --- |
| `한 칸` | `1` |
| `좌우 2등분` | `2` |
| `위아래 2등분` | `1-1` |
| `위 2 · 아래 1` | `2-1` |
| `위 1 · 아래 2` | `1-2` |
| `2 x 2` | `2-2` |
| `3단` | `3` |
| `위아래 3등분` | `1-1-1` |

고른 뒤에도 칸을 더 넣고 뺄 수 있다. 칸에 마우스를 올리면

- 좌우 `+` 는 같은 행에 칸을 하나 더 넣고,
- 상하 `+` 는 위/아래에 새 행을 넣고,
- 오른쪽 위 `−` 는 그 칸을 지운다. 안에 있던 내용은 옆 칸으로 옮겨간다.
  마지막 한 칸은 남는다.

도구막대의 `열 - / +` 도 고른 칸이 속한 행의 칸 수를 바꾼다.

### 칸에 내용 넣기

빈 칸 가운데에 `글목록` `그림` `표` `코드` 칩이 뜬다. 누르면 그 자리에 들어간다.
내용이 있는 칸에서는 같은 칩이 오른쪽 아래에 작게 붙어, 한 칸에 여러 블록을
쌓을 수 있다. 이미 있는 블록은 왼쪽 위 손잡이를 끌어 다른 칸으로 옮긴다.
글을 편집하는 것과 겹치지 않도록 옮기기는 손잡이로만 한다.

### 경계 끌기

행과 행 사이, 칸과 칸 사이에 파란 손잡이가 뜬다. 끌면 맞닿은 둘이 크기를
주고받고 나머지는 그대로다. 값은 `--cde-rtpl`(행), `--cde-ctpl`(칸) 에 `fr` 로
저장되고, 칸을 넣거나 빼면 초기화된다. 본문 바깥 네 변의 호박색 손잡이는
그대로 본문 여백을 조절한다.

나뉜 모양은 `.body` 의 `data-cde-grid="2-1"` 과 `--cde-rows` 로 저장된다.
표 안의 행·열 경계 손잡이는 등분 배치에서도 그대로 쓴다.

덱이 스스로 만든 격자 - `.cols` 같은 자체 2단 - 에도 같은 손잡이가 붙는다.
쓸 변수가 없으면 트랙 크기를 그 요소의 `grid-template-columns` / `-rows` 에 직접
적는다. 한 경계에 손잡이는 하나뿐이다.

### 예전 두 영역 모델

`data-cde-layout` (글 영역 + 그림 영역) 으로 저장된 기존 덱은 그대로 열리고
경계도 그대로 끌린다. 새로 배치를 고르면 그 장은 등분 모델로 바뀐다.
덱이 같은 모델을 자기 이름(`data-layout`, `.body-media`, `--split`)으로 쓰면
그 이름 그대로 읽고 쓴다.

## 글자 크기

도구막대의 `글자 A- / A+` 로 조절한다. 한 번에 8% 씩, 50% 에서 250% 사이.

- 블록을 고른 상태면 그 블록과 그 안의 글만 바뀐다. 클릭은 가장 안쪽 블록을
  고른다 - 덱의 2단 안에 있는 표를 누르면 슬라이드 절반이 아니라 그 표가 잡힌다.
- 아무것도 고르지 않았으면 그 슬라이드 본문 전체가 바뀐다. 제목과 꼬리말은
  그대로 둔다.
- 크기는 각 요소의 `font-size` 에 `px` 로 직접 적힌다. 에디터를 끄고 열어도,
  PDF 로 뽑아도 그대로다. 배율은 `data-cde-fs` 에 남아 도구막대에 표시된다.

## 그림

- 그림에 마우스를 올리면 상하좌우에 `+` 버튼이 뜬다. 누른 방향에 새 그림이 들어간다.
- 좌우로 넣으면 열이 하나 늘어난다. 상하로 넣으면 그 자리 위/아래 행에 들어간다.
- 그림 영역은 균일 격자다. 모든 칸이 같은 크기라 오와 열이 맞는다.
  열 수는 도구막대의 `열 - / +` 로 바꾼다.
- 우상단 `×` 로 삭제한다. 그림을 지우면 열 수도 함께 되돌아간다.
- 올린 파일은 덱 폴더의 `imgs/` 에 저장되고 상대 경로로 삽입된다.
  같은 이름이 있으면 `-2` 를 붙여 기존 파일을 보존한다.

## 글과 항목

- 제목, 불릿, 표 칸, 카드는 바로 고쳐 쓴다.
- 항목을 클릭하면 파란 테두리로 선택되고 `Del` 로 지운다.
  글 안에서 편집 중일 때는 `Del` 이 글자를 지운다. `Esc` 로 편집에서 빠져나온 뒤
  `Del` 을 누르면 그 블록이 지워진다.
- 불릿 하나, 표 하나, 그림 하나 모두 개별 삭제 대상이다.
- 덱이 자체 배치(`.body-media`)를 쓰는 슬라이드의 그림과 표에도 `×` 가 붙는다.
  지우면 남은 개수에 맞춰 열 수가 줄고, 모두 지우면 글만 남는 배치로 바뀐다.
- 글 영역의 블록(카드, 목록, 문단)에 마우스를 올리면 우상단 `×`(삭제)와
  하단 가운데 `+`(아래에 같은 형식의 블록 추가)가 나타난다. 추가된 블록은 `새 내용` 이 선택된 상태로 열린다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `PageDown` / `PageUp` | 다음 / 이전 슬라이드 |
| `Home` / `End` | 첫 장 / 마지막 장 |
| `Alt+↑` / `Alt+↓` | 선택한 슬라이드를 앞 / 뒤로 이동 |
| `Ctrl+S` | 저장 |
| `Ctrl+Z` | 되돌리기 |
| `Esc` | 글 편집에서 빠져나오기 |
| `Del` | 슬라이드 안에서는 선택한 항목 삭제, 왼쪽 목록에서는 슬라이드 통째로 삭제 |

슬라이드 안에 초점이 있어도 동작한다. 글을 쓰는 중에도 `PageUp` / `PageDown` 과
`Ctrl+S` 는 그대로 듣는다.

## 되돌리기

`Ctrl+Z` 또는 도구막대의 `되돌리기`. 배치 변경, 칸 추가/삭제, 칸 사이 이동,
그림·표·코드 추가, 항목 삭제, 슬라이드 추가·삭제·순서 변경, 글자 크기, 크기 조절,
글 수정이 모두 한 단계씩 되돌아간다. 최근 60 단계까지 쌓인다.

글 상자 안에서 편집 중일 때는 `Ctrl+Z` 가 브라우저의 글자 되돌리기로 간다.
블록 자체를 되돌리려면 `Esc` 로 편집에서 빠져나온 뒤 누른다.

## 표

표의 행 경계에는 청록색, 열 경계에는 보라색 손잡이가 붙는다.

열을 끌면 맞닿은 두 열이 폭을 주고받고 표 전체 폭은 그대로다. 폭은 표 안의
`<colgroup>` 에 퍼센트로 저장되고, 그 표만 `table-layout: fixed` 로 바뀐다.

행 경계를 끌면 행 높이가 바뀌며, 표 전체가 한
행 높이를 공유하므로 어느 경계를 끌든 행이 고르게 유지된다. 손잡이 폭은 표 폭에
맞춰져 옆 그림을 가리지 않는다. 값은 표 자체의 `--cde-trow` 와 `data-cde-trow` 로
저장되므로, 표가 글 영역에 있든 그림 영역에 있든 등분 칸에 있든 똑같이 듣는다.

## 저장

- `저장` 또는 `Ctrl+S` - 열려 있는 그 파일에 바로 쓴다.
- `다른 이름으로 저장` - 같은 폴더에 새 이름으로 쓴다. 덮어쓰기는 한 번 더 묻는다.
- `자동 저장` 체크 시 마지막 수정 1.2 초 뒤에 자동으로 쓴다.
- 다른 도구가 파일을 고치면 2 초 안에 감지해서 다시 읽는다.
  단, 저장하지 않은 변경이 있으면 덮지 않고 기다린다.

저장할 때 에디터 UI(`data-cde-ui`), `contenteditable`, 화면 맞춤용 임시 스타일은
모두 빠진다. 남는 것은 배치 정보(`data-cde-grid`, `--cde-rows`, `--cde-rtpl`,
`--cde-ctpl`)와 글자 크기(`font-size`, `data-cde-fs`)뿐이다.

## 덱에 남는 것

에디터를 켜면 덱 폴더에 `cde-layout.css` 를 깔고 덱 HTML 에
`<link rel="stylesheet" href="cde-layout.css">` 를 넣는다. 이 파일이 있어야
에디터를 끈 뒤에도, PDF 로 뽑을 때도 레이아웃이 유지된다.
덱을 다른 곳으로 옮기면 이 파일도 같이 옮긴다.

## 덱별 설정

덱 폴더에 `cde.config.json` 을 두면 선택자를 바꿀 수 있다. 없으면 기본값을 쓴다.

```json
{
  "slide": "section.slide",
  "body": ".body",
  "media": "figure, table, .tbl, .fig-stack, img, svg, pre",
  "editable": ".title, .ul li, .tbl td, .card, p",
  "imageDir": "imgs",
  "autosave": true
}
```

## 안전

- 127.0.0.1 에만 바인딩한다.
- 모든 쓰기는 대상 폴더 안으로 제한된다. `..`, `%2e%2e` 로 빠져나갈 수 없다.
- 쓰기 가능한 확장자는 `.html .htm .css .js .svg .md .json`,
  업로드는 `.png .jpg .jpeg .gif .svg .webp .avif` 로 한정된다.

## 한계

정규화는 원래 덱의 배치를 그대로 재현하는 것이 목표지만 픽셀 단위로 같지는 않다.
20 장짜리 덱으로 잰 평균 차이는 8 퍼센트 수준이며, 대부분은 그림이 배정된 영역을
가득 채우도록 바뀌면서 생기는 높이 차이다. 이는 의도한 동작이다.
간격이 마음에 들지 않으면 `--cde-gap`(글과 그림 사이), `--cde-fgap`(그림 사이) 를
슬라이드나 덱 단위로 지정한다.
