# Claude Design Editor

정적 HTML 덱을 파워포인트처럼 편집하는 로컬 에디터. 프로젝트에 종속되지 않고,
`section.slide` 구조의 HTML 덱이면 어디서든 쓴다.

```bash
python3 editor.py /path/to/deck-dir        # 폴더의 첫 HTML 을 연다
python3 editor.py /path/to/deck.html       # 특정 파일을 연다
python3 editor.py . --port 8770 --no-open
```

브라우저가 `http://127.0.0.1:8770/` 로 열린다. 크롬 기준으로 만들었다.
파이썬 표준 라이브러리만 쓴다. 설치할 것 없다.

## 화면

- 왼쪽: 슬라이드 목록. 실제 렌더링을 축소한 썸네일이라 보이는 그대로다.
- 오른쪽: 선택한 슬라이드. 창 크기에 맞춰 자동 축소된다.
- 가운데 회색 띠를 끌면 좌우 폭이 바뀐다.

덱은 iframe 두 개(스테이지 / 목록)로 렌더링한다. 덱 자신의 CSS 가 그대로 쓰이므로
에디터가 모양을 다시 구현하지 않고, 인쇄 결과도 달라지지 않는다.

## 레이아웃

각 장의 본문은 **글 영역**과 **그림 영역** 둘로 나뉜다. 표는 그림 영역에 들어간다.

| 레이아웃 | 배치 |
| --- | --- |
| `글 위 · 그림 아래` | 세로 2단 |
| `글 왼쪽 · 그림 오른쪽` | 가로 2단 |
| `그림 왼쪽 · 글 오른쪽` | 가로 2단 반전 |
| `그림 위 · 글 아래` | 세로 2단 반전 |
| `2단 · 각 단에 글 위 그림 아래` | 왼쪽 글1/그림1, 오른쪽 글2/그림2 |
| `글만` / `그림만` | 1단 |

두 영역 경계에 마우스를 올리면 파란 손잡이가 뜬다. 끌면 좌우 레이아웃은 좌우로,
상하 레이아웃은 상하로 비율이 바뀐다. 비율은 `--cde-a` 로 저장된다.
2단 레이아웃은 손잡이가 셋이다. 가운데 세로선 하나와 각 단의 가로선 둘이며,
단 안쪽 비율은 `--cde-row` 로 저장된다.

그림 영역 안의 칸 경계에도 손잡이가 붙는다. 그림과 그림, 그림과 표 사이를 끌면
맞닿은 두 칸이 폭(또는 높이)을 주고받고 나머지 칸은 그대로 있다. 격자 단위로
움직이므로 오와 열은 계속 맞는다. 값은 `--cde-ctpl`(열), `--cde-rtpl`(행) 에
`fr` 로 저장되며, 열 수를 바꾸거나 그림을 넣고 빼면 초기화된다.

기존 덱을 처음 열면 원래 구조에서 레이아웃과 열 수를 추론한다. 글이 2단 안에
들어 있으면 좌우 배치, 그림 위에 있으면 세로 배치로 본다. 표가 섞인 2단은
열 수를 늘리지 않는다.

## 그림

- 그림에 마우스를 올리면 상하좌우에 `+` 버튼이 뜬다. 누른 방향에 새 그림이 들어간다.
- 좌우로 넣으면 열이 하나 늘어난다. 상하로 넣으면 그 자리 위/아래 행에 들어간다.
- 그림 영역은 균일 격자다. 모든 칸이 같은 크기라 오와 열이 맞는다.
  열 수는 도구막대의 `열 - / +` 로 바꾼다.
- 우상단 `×` 로 삭제한다. 그림을 지우면 열 수도 함께 되돌아간다.
- 올린 파일은 덱 폴더의 `imgs/` 에 저장되고 상대 경로로 삽입된다.
  같은 이름이 있으면 `-2` 를 붙여 기존 파일을 보존한다.

## 글과 항목

- 제목, 불릿, 표 칸, 카드는 바로 고쳐 쓴다.
- 항목을 클릭하면 파란 테두리로 선택되고 `Del` 로 지운다.
  글 안에서 편집 중일 때는 `Del` 이 글자를 지운다. `Esc` 로 편집에서 빠져나온 뒤
  `Del` 을 누르면 그 블록이 지워진다.
- 불릿 하나, 표 하나, 그림 하나 모두 개별 삭제 대상이다.

## 저장

- `저장` 또는 `Ctrl+S` - 열려 있는 그 파일에 바로 쓴다.
- `다른 이름으로 저장` - 같은 폴더에 새 이름으로 쓴다. 덮어쓰기는 한 번 더 묻는다.
- `자동 저장` 체크 시 마지막 수정 1.2 초 뒤에 자동으로 쓴다.
- 다른 도구가 파일을 고치면 2 초 안에 감지해서 다시 읽는다.
  단, 저장하지 않은 변경이 있으면 덮지 않고 기다린다.

저장할 때 에디터 UI(`data-cde-ui`), `contenteditable`, 화면 맞춤용 임시 스타일은
모두 빠진다. 남는 것은 레이아웃 정보(`data-cde-layout`, `--cde-a`, `--cde-cols`)뿐이다.

## 덱에 남는 것

에디터를 켜면 덱 폴더에 `cde-layout.css` 를 깔고 덱 HTML 에
`<link rel="stylesheet" href="cde-layout.css">` 를 넣는다. 이 파일이 있어야
에디터를 끈 뒤에도, PDF 로 뽑을 때도 레이아웃이 유지된다.
덱을 다른 곳으로 옮기면 이 파일도 같이 옮긴다.

## 덱별 설정

덱 폴더에 `cde.config.json` 을 두면 선택자를 바꿀 수 있다. 없으면 기본값을 쓴다.

```json
{
  "slide": "section.slide",
  "body": ".body",
  "media": "figure, table, .tbl, .fig-stack, img, svg, pre",
  "editable": ".title, .ul li, .tbl td, .card, p",
  "imageDir": "imgs",
  "autosave": true
}
```

## 안전

- 127.0.0.1 에만 바인딩한다.
- 모든 쓰기는 대상 폴더 안으로 제한된다. `..`, `%2e%2e` 로 빠져나갈 수 없다.
- 쓰기 가능한 확장자는 `.html .htm .css .js .svg .md .json`,
  업로드는 `.png .jpg .jpeg .gif .svg .webp .avif` 로 한정된다.

## 한계

정규화는 원래 덱의 배치를 그대로 재현하는 것이 목표지만 픽셀 단위로 같지는 않다.
20 장짜리 덱으로 잰 평균 차이는 8 퍼센트 수준이며, 대부분은 그림이 배정된 영역을
가득 채우도록 바뀌면서 생기는 높이 차이다. 이는 의도한 동작이다.
간격이 마음에 들지 않으면 `--cde-gap`(글과 그림 사이), `--cde-fgap`(그림 사이) 를
슬라이드나 덱 단위로 지정한다.
